# FT_IRC

**An IRC server with AI-powered agents.**


## Overview

FT_IRC is an implementation of an Internet Relay Chat (IRC) server. It supports multiple client connections, channels, and AI agents powered by [Ollama](https://ollama.com/). Users can connect with a standard IRC client or interact with the server directly from a terminal.

The project is developed with reference to the IRC protocol specifications, including [RFC 1459](https://www.rfc-editor.org/rfc/rfc1459), [RFC 2812](https://www.rfc-editor.org/rfc/rfc2812) (client protocol), and [RFC 2813](https://www.rfc-editor.org/rfc/rfc2813) (server protocol).

## Features

- Multiple clients connected to the server simultaneously.
- IRC channels and channel-based communication.
- IRC command handling and client registration.
- AI agents integrated through Ollama, with responses generated by large language models (LLMs).

## Getting started

### Build

Compile the project using the Makefile:

```bash
make
```

### Run the server

Start the server with a port and a connection password:

```bash
./ircserv <port> <password>
```

| Argument | Description |
| --- | --- |
| `<port>` | TCP port the server will listen on. |
| `<password>` | Password clients must provide when connecting. |

### Connect to the server

You can connect using any compatible IRC client. For a quick terminal-based connection, use `netcat`:

```bash
nc -C localhost 8080
```

Replace `8080` with the port passed to `ircserv`. The `-C` option makes `netcat` use CRLF line endings, as expected by IRC message framing.

### Register your client

After connecting, register your client by sending the following commands in order. Replace the placeholders with your own values:

```irc
PASS <password>
NICK <nickname>
USER <username> 0 0 :<real name>
```

- `PASS` provides the server password. Send it before the registration commands.
- `NICK` sets your IRC nickname.
- `USER` supplies your username and real name. The final parameter is the real name, not the hostname; the leading `:` allows it to contain spaces.

Once registration succeeds, you can start using the server and joining channels.

## AI agents

FT_IRC integrates AI agents through Ollama. Each agent uses an LLM to generate conversational responses and follows its own personality prompt.

Agents can also carry out supported IRC actions when a user explicitly requests them. These actions are executed on behalf of the user who sent the request, through that user's IRC connection. As a result, an agent inherits the requesting user's permissions; it does not grant the user additional privileges. The server remains responsible for checking permissions and accepting or rejecting each command.

## AI usage

AI was used in several parts of this project:

- AI generated the text-based personality prompts used by the bots.
- Ollama and LLMs are used to generate the bots' conversational responses.
- AI-assisted code completion was used in some source files. Some generated comments may remain in the codebase.
- This readme was typo checked by AI.
